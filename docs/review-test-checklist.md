# 评价功能回归清单

## 用户端

1. 完成一个含多商品的订单，确认仅在订单完成后可进入评价。
2. 分别提交好评、中评、差评，确认每个订单明细必须各自评价。
3. 评价内容分别测试 255 字、500 字和超过 500 字的边界。
4. 上传多张图片后立刻点击发布，确认按钮提示上传中且不会提交临时图片路径。
5. 分别测试匿名和非匿名评价，确认商品评价列表中的昵称、头像符合预期。
6. 在商品详情查看评价摘要、评价图片、商家回复，并进入“查看全部”验证全部/有图/好评筛选和大图预览。
7. 在订单“评价”页测试待评价、已评价和订单评价详情。
8. 对同一订单连续点击发布或重复请求，确认只能成功一次。

## 商家端

1. 仅能看到当前登录店铺的评价。
2. 验证好评/中评/差评、有图、已回复/未回复筛选。
3. 查看评价详情及图片，新增回复、修改回复后确认 App 商品评价列表和详情摘要同步展示。
4. 使用无权店铺 ID 调用评价详情和回复接口，确认被拒绝。

## 平台端

1. 验证公开状态、评价等级、有图、回复状态筛选及详情图片预览。
2. 隐藏评价时必须填写原因；隐藏后 App 列表、商品详情统计和有图/好评统计均不再包含该评价。
3. 恢复公开后确认 App 列表和统计恢复，平台详情可查看治理备注。
