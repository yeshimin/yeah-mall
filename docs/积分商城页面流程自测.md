# 积分商城页面流程自测

## 0. 测试前

1. 人工执行 `sql/05_member_points_schema.sql`。
2. 重启后端，平台后台退出后重新登录。
3. App 使用有积分的会员账号登录。

## 1. 实物商品完整流程

1. 平台后台：`商城管理 -> 积分商城 -> 商品分类`，新增并启用分类。
2. 平台后台：`商城管理 -> 积分商城 -> 积分商品`，新增“实物商品”，先保持下架。
3. 点击商品的 `SKU管理`，新增 SKU，填写积分价格和库存。
4. 编辑商品并上架。
5. App：`我的 -> 我的积分 -> 去积分商城逛逛`。
6. 进入商品，选择 SKU 和数量，点击 `立即兑换`，选择地址并确认。
7. App：积分订单应为“待履约”，积分和库存应扣减。
8. 平台后台：`积分商城 -> 兑换订单`，点击 `发货`。
9. App：`兑换记录 -> 订单详情 -> 确认收货`，订单变为“已完成”。

## 2. 优惠券商品完整流程

1. 商家后台：`优惠券管理 -> 优惠券管理`，新增或编辑优惠券，开启 `积分兑换`。
2. 平台后台：新增“优惠券”积分商品，选择该优惠券，配置 SKU 后上架。
3. App 进入积分商城并兑换该商品。
4. 兑换后订单应直接“已完成”，优惠券出现在 `我的优惠券`。
5. 商家后台：`优惠券管理 -> 使用记录`，领取渠道应显示“积分兑换”。

## 3. 无物流权益完整流程

1. 平台后台：新增“虚拟权益”积分商品，配置 SKU 后上架。
2. App 兑换时不应要求选择收货地址，订单进入“待履约”。
3. 平台后台：`积分商城 -> 兑换订单 -> 完成履约`，填写履约说明。
4. App 订单详情应显示“已完成”和履约说明。

## 4. 取消与退回

1. App 兑换一个实物商品或虚拟权益，保持“待履约”。
2. 在订单详情点击 `取消兑换`。
3. 订单应变为“已取消”，积分和 SKU 库存应恢复。
4. 自动发券订单不应出现取消按钮。

## 5. 页面入口汇总

- 平台会员积分调整：`商城管理 -> 会员管理 -> 更多`。
- 平台积分流水与规则：`商城管理 -> 积分管理`。
- 平台积分商品与订单：`商城管理 -> 积分商城`。
- 商家积分券开关：`优惠券管理 -> 优惠券管理`。
- App 积分商城：`我的 -> 我的积分 -> 去积分商城逛逛`。
- App 积分订单：积分商城右下角 `兑换记录`。
