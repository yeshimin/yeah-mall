# 拼团两人成团联调清单

## 准备

- 启动最新后端、管理后台和 App；确认拼团建表脚本已人工执行。
- 准备一个平台账号、一个商家账号，以及两个不同的 App 会员账号（会员 A、会员 B）。
- 商家先创建一个至少有一个 SKU、库存充足、商品主图完整的普通商品。
- 为快速联调，活动时间可设为：报名窗口 2 分钟、活动窗口 20 分钟、`最低成团人数 = 2`、`成团有效时长 = 10 分钟`。
- 报名结束时间不得晚于活动开始时间。测试支付仍固定为一分钱。

## 成功链路

1. 平台后台，进入“拼团管理 -> 活动管理”，新建活动并上传封面。
2. 平台后台，依次操作“发布 -> 开始报名”。
3. 商家后台，进入“拼团管理 -> 活动管理”，选择该活动并提交商品报名。
4. 平台后台，进入“拼团管理 -> 申请审核”，审核通过该商品报名。
5. 报名窗口结束后，平台后台依次操作“结束报名 -> 开始活动”，并启用活动。
6. App 使用会员 A 登录：首页“拼团”入口 -> 进入活动 -> 选择已审核商品 -> 选择 SKU -> 选择“发起新团” -> 确认订单并支付。
7. 验证会员 A 订单状态为“待成团”；平台/商家“拼团订单”可见该订单，团状态为拼团中。
8. App 使用会员 B 登录，进入同一拼团商品，选择会员 A 创建且显示 `1/2` 的团 -> 选择 SKU -> 确认订单并支付。
9. 验证两笔订单均变为“待发货”，团状态变为“已成团”。
10. 商家后台使用常规“订单管理”对两笔订单发货；两个会员在 App 订单详情中确认收货。

## 优惠券校验

1. 给会员 A 准备一张满足门槛的店铺、商品或分类优惠券。
2. 在第 6 步的确认订单页选择优惠券。
3. 验证优惠券列表可见且金额按拼团价计算，不按原商品售价计算。
4. 验证订单保存“商品总额、优惠金额、优惠后应付金额”。

## 可选失败链路

1. 新建另一活动，设置“成团有效时长 = 1 分钟”，仍为 2 人团。
2. 仅用会员 A 开团并完成支付，不让会员 B 参团。
3. 等待定时任务执行。
4. 验证团状态变为“拼团失败”，订单进入退款流程，拼团 SKU 库存回补。
